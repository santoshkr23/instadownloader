How to get cookies.txt
  1. On a computer, install the Chrome extension Get cookies.txt LOCALLY and allow it in Incognito.
  2. Open an Incognito window, sign in to YouTube with a spare account.
  3. Go to youtube.com/robots.txt, click the extension → Export.
  4. Close the Incognito window (don't sign out), then upload the file here.
